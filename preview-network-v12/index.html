这条链是"产城人"闭环：产业投入 → 创新 → 工资 → 本地消费 → 生活配套 → 人才留驻 → 再投入。

数字＝这一环的传导力度（越大越紧）。"工资 → 本地消费"设定为 0.35，是模型中最低的一环。实际消费流向尚需调查，不能断言工人的钱流去了某个具体地方。这些力度是按公开信息推算的（可信度 D：推算值·待核实），数值只说明松紧方向，不是实测。
