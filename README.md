# 仲恺区域经济沙盘 · 云实验室版 newzk-simulator

仲恺高新区的第二个版本。在原来的产业底图上，加了可以自己动手的实验室面板：换条件、改路径、看结果怎么跟着变。单文件离线，双击即开。

## 打开方式

下载后双击 `index.html`，任意现代浏览器打开。不需要联网、不需要安装、不上传数据。

## 页面清单

| 页面 | 看什么 |
|---|---|
| `index.html` | 入口与今日概况 |
| `network.html` | 全区产业主体与它们之间的关系，谁连接最多、谁在最外圈 |
| `choices.html` | 几条发展路径可以逐条打开或关闭，看打开组合之后的样子 |
| `future.html` | 同一条件下反复运行，结果落在什么区间 |
| `blindspot.html` | 容易被忽略的几处，摆在明面上 |
| `mylife.html` | 生活视角：镇上有什么、当季吃什么 |
| `guide.html` | 使用说明与数据来源 |
| `ending.html` | 收尾 |

## 数据来源

统计公报、管委会工作报告、政府门户与主流媒体公开报道。页面标注来源与更新时间；查不到的一律标"暂缺"。
